# OpenD

[English](README.md) · **Русский**

Крошечный тёмный загрузчик YouTube для Windows 10/11, живёт в трее. Скопировали ссылку, нажали горячую клавишу — в правом нижнем углу маленький HUD с ходом загрузки. Загрузки переживают перезагрузку ПК и обрывы интернета.

Работает на открытых инструментах: [yt-dlp](https://github.com/yt-dlp/yt-dlp) (скачивание), [ffmpeg](https://ffmpeg.org) (склейка видео и звука), [Deno](https://deno.com) (проверки YouTube) и Microsoft Edge WebView2 (окно входа). Шрифты интерфейса: [Montserrat](https://github.com/JulietaUla/Montserrat) и [Comfortaa](https://github.com/googlefonts/comfortaa) (лицензия SIL OFL, см. `assets/fonts`).

Нужно: Windows 10/11 (.NET Framework 4.8 уже встроен) и Edge WebView2 Runtime (в Windows 11 он есть).
При первом запуске OpenD сам скачает yt-dlp, ffmpeg и Deno в `%APPDATA%\OpenD\bin` (около 150 МБ, нужен интернет; без интернета программа ждёт и повторяет попытки). Дальше yt-dlp обновляется сам.

## Как пользоваться

1. Запустите `OpenD.exe`. Программа живёт в системном трее.
2. **Войдите один раз** (YouTube требует «подтвердите, что вы не бот»): значок в трее → правый клик → **Войти в YouTube…**, войдите в аккаунт и нажмите **Готово**. Используйте отдельный ненужный аккаунт Google, а не основной.
3. Скопируйте ссылку на видео YouTube и нажмите **Ctrl+Alt+D**. В правом нижнем углу появится маленький HUD с названием и процентами.
4. Левый клик по значку в трее открывает окно очереди. **Ctrl+Alt+H** показывает или скрывает HUD.

По желанию: **Настройки → Следить за буфером** добавляет ссылки автоматически, без горячей клавиши.

## Что умеет

- Глобальные горячие клавиши, трей, подхват ссылок из буфера, компактный минималистичный тёмный интерфейс (Montserrat + Comfortaa).
- Мини-HUD: только название и процент, не забирает фокус, появляется во время загрузок и сам исчезает. Можно отключить или переключать горячей клавишей.
- Окно очереди с аккуратной раскладкой без «дёрганья»: процент, размер, скорость и время стоят в колонках фиксированной ширины. Панель значков с подсветкой и подсказками.
- Очередь хранится на диске: после перезагрузки или сбоя загрузки продолжаются с места остановки.
- **Устойчивость к сети**: если интернет пропал, загрузки ждут («Нет сети, повтор через N с»), повторяют попытки с растущей паузой и сами продолжаются, когда связь вернулась. Недокачанные файлы докачиваются, а не начинаются заново.
- Качество: **Оригинал** (лучшие потоки без перекодирования), 2160p, 1440p, 1080p, 720p, 480p, MP4 H.264, только звук (оригинал) или MP3.
- Контейнер: Авто, MP4, MKV, WebM.
- В каждой строке: размер, скорость, оставшееся время, метка *ОРИГИНАЛ* и точный формат (например `ОРИГИНАЛ 1080p AV1 WEBM`). Готовые видео ярче ожидающих.
- Четыре постоянных слота значков в строке: папка именно этого файла (файл выделен), пауза / продолжить, стоп (стирает недокачанное), убрать. Правый клик: открыть файл, копировать ссылку, показать ошибку, удалить вместе с файлом.
- Если файл удалили через проводник, в списке он помечается «Удалён» и скачивается заново одним кликом. yt-dlp и ffmpeg работают в Job Object Windows, поэтому процессы-сироты не держат файлы занятыми.
- Настройки: запуск с Windows, запуск свёрнутым в трей или с окном, слежение за буфером, мини-окно вкл/выкл, **переназначаемые горячие клавиши**, папка загрузки, вход в YouTube.
- До 2 загрузок одновременно, yt-dlp обновляется раз в сутки и после сбоя.
- Журнал отладки: трей → **Открыть лог** (`%APPDATA%\OpenD\log.txt`).

Видео сохраняются в `Видео\OpenD`. Настройки и очередь лежат в `%APPDATA%\OpenD`.

## Если что-то не так

| Проблема | Решение |
| --- | --- |
| «Sign in to confirm you're not a bot» | Трей → **Войти в YouTube…**. Это надёжный способ, в том числе через VPN. |
| Cookies из Chrome/Edge не работают | Новый Chrome шифрует cookies так, что другие программы их не читают. Используйте **Войти в YouTube…**. |
| Горячая клавиша занята | Откройте **Настройки**, нажмите на поле клавиши и введите другое сочетание. |
| Другая ошибка | Трей → **Открыть лог** и посмотрите последние строки. |

Необязательное поле `Proxy` в `settings.json` (например `http://127.0.0.1:8080`) направляет yt-dlp через прокси.

## Сборка из исходников

```
build.cmd
```

Используется компилятор C#, который есть в Windows (.NET Framework 4.8), ничего ставить не нужно. Результат в `dist\`. DLL WebView2 лежат в `lib\`, шрифты из `assets\fonts\` вшиваются в exe.

## Юридически

Для личного использования. Соблюдайте авторские права и условия YouTube: скачивайте только то, что вам разрешено.
