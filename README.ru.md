# OpenD

[English](README.md) · **Русский**

Крошечный тёмный загрузчик YouTube для Windows 10/11, живёт в трее. Скопировали ссылку, нажали горячую клавишу — в правом нижнем углу мини-HUD с ходом загрузки. Загрузки переживают перезагрузку ПК.

Работает на открытых инструментах: [yt-dlp](https://github.com/yt-dlp/yt-dlp) (скачивание), [ffmpeg](https://ffmpeg.org) (склейка видео и звука), [Deno](https://deno.com) (проверки YouTube) и Microsoft Edge WebView2 (окно входа).

Нужно: Windows 10/11 (.NET Framework 4.8 уже встроен) и Edge WebView2 Runtime (в Windows 11 он есть).
При первом запуске OpenD сам скачает yt-dlp, ffmpeg и Deno в `%APPDATA%\OpenD\bin` (около 150 МБ, нужен интернет). Дальше yt-dlp обновляется сам.

## Как пользоваться

1. Запустите `OpenD.exe`. Программа живёт в системном трее.
2. **Войдите один раз** (YouTube требует «подтвердите, что вы не бот»): значок в трее → правый клик → **Войти в YouTube…**, войдите в аккаунт и нажмите **Готово**. Используйте отдельный ненужный аккаунт Google, а не основной.
3. Скопируйте ссылку на видео YouTube и нажмите **Ctrl+Alt+D**. В правом нижнем углу появится HUD с процентами, скоростью и оставшимся временем.
4. Левый клик по значку в трее открывает окно очереди.

По желанию: в трее **Следить за буфером** добавляет ссылки автоматически, без горячей клавиши.

## Что умеет

- Глобальная горячая клавиша, трей, подхват ссылок из буфера, компактный минималистичный тёмный интерфейс.
- Мини-HUD: не забирает фокус, висит пока идут загрузки, сам исчезает.
- Очередь хранится на диске: после перезагрузки загрузки продолжаются с места остановки.
- Качество: **Оригинал** (лучшие потоки без перекодирования), 2160p, 1440p, 1080p, 720p, 480p, MP4 H.264, только звук (оригинал) или MP3.
- Контейнер: Авто, MP4, MKV, WebM.
- В каждой строке: размер, скорость, оставшееся время, метка *ОРИГИНАЛ* и точный формат (например `ОРИГИНАЛ · 1080p · AV1 · Opus · WEBM`).
- Кнопки в строке: папка именно этого файла (файл выделен), пауза / продолжить, стоп (стирает недокачанное), удалить. Правый клик: открыть файл, копировать ссылку, показать ошибку, удалить вместе с файлом.
- Настройки: запуск с Windows, запуск свёрнутым в трей или с окном, слежение за буфером, папка загрузки.
- До 2 загрузок одновременно, yt-dlp обновляется раз в сутки и после сбоя.
- Журнал отладки: трей → **Открыть лог** (`%APPDATA%\OpenD\log.txt`).

Видео сохраняются в `Видео\OpenD`. Настройки и очередь лежат в `%APPDATA%\OpenD`.

## Если что-то не так

| Проблема | Решение |
| --- | --- |
| «Sign in to confirm you're not a bot» | Трей → **Войти в YouTube…**. Это надёжный способ, в том числе через VPN. |
| Cookies из Chrome/Edge не работают | Новый Chrome шифрует cookies так, что другие программы их не читают. Используйте **Войти в YouTube…**. |
| Горячая клавиша занята | Измените `Mods` и `Key` в `%APPDATA%\OpenD\settings.json` (Mods: 1=Alt, 2=Ctrl, 4=Shift, 8=Win, суммируются; Key: код клавиши, 68 = D). |
| Другая ошибка | Трей → **Открыть лог** и посмотрите последние строки. |

## Сборка из исходников

```
build.cmd
```

Используется компилятор C#, который есть в Windows (.NET Framework 4.8), ничего ставить не нужно. Результат в `dist\`. DLL WebView2 лежат в `lib\`.

## Юридически

Для личного использования. Соблюдайте авторские права и условия YouTube: скачивайте только то, что вам разрешено.
